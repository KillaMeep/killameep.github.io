Things I've built.

Open-source tools, mostly about pixels: desktop apps, computer vision and a little OSINT. Everything lives on GitHub.

01

Waypoint

Free, open-source image geolocation. Give it one outdoor photo and it estimates where on Earth it was taken: a diffusion model makes coarse guesses, sun position rules out bad ones, and matches against real street-level imagery confirm the rest, all on an interactive map.

  • Electron
  • Python
  • PyTorch
  • OSINT
  • LightGlue
source
02

Glyphify

A desktop app that turns images and videos into ASCII art. Color or grayscale, a pile of character sets (including braille and custom ones), live tuning, and export to TXT, HTML, PNG or animated GIF.

  • Electron
  • JavaScript
  • FFmpeg
  • Desktop app
source
03

ASCII-gen

An open-source tool that converts images and video frames into ASCII art. It handles static images and animated GIFs, and runs on both Linux and Windows.

  • Python
  • Image processing
  • GIF + video
  • Cross-platform
source
04

StarNodeAnimator

Creates customizable star-field animations with OpenGL in Pygame. Tweak everything from a GUI, then export the result as an MP4.

  • Python
  • Pygame
  • OpenGL
  • MP4 export
source
05

BeatBlock AI

Real-time object detection for BeatBlock, a rhythm game by BubbleTabby. Built on YOLOv5 to spot in-game elements with low latency for gameplay analysis.

  • Python
  • YOLOv5
  • Computer vision
  • Real-time
